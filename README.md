# SpotFinder Platform

SpotFinder is a full-stack web application where users can discover places, create listings, upload images, write reviews, and manage content through authenticated user flows.

## Tech Stack

This project is built using **Node.js**, **Express.js**, **MongoDB**, **Mongoose**, **EJS**, **Bootstrap**, **HTML**, **CSS**, and **JavaScript**. It uses **Passport.js** and **Express Sessions** for authentication, protected routes and ownership checks for authorization, **Cloudinary** and **Multer** for image uploads, **Joi** for request validation, custom middleware for error handling, and **connect-flash** for user feedback. I also used **ChatGPT** as an AI coding assistant during development, and I reviewed, tested, and customized the code instead of directly relying on generated output.

## Features

* User signup, login, logout, and session-based authentication
* Authorization for protected routes and user-owned content
* Create, read, update, and delete listings
* Add and delete reviews with validation
* Upload listing images using Cloudinary
* Organized backend code using controllers and route handlers
* Request validation using Joi
* Centralized error handling with custom middleware
* Flash messages for user feedback
* Responsive UI using EJS templates and Bootstrap

## Status

Core full-stack features are implemented, including authentication, authorization, listing CRUD, reviews, validation, Cloudinary image uploads, and error handling.

I am continuing to improve the project with deployment polish, map/location integration, search/filtering, security improvements, and AI-powered features.
